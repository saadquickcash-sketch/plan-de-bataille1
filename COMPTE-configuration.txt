PLAN DE BATAILLE — ACTIVER LES COMPTES (gratuit, ~5 minutes)
=============================================================

Le site marche sans compte. Pour activer l'inscription/connexion
(email + Google) et sauvegarder les conversations sur le compte de
chaque utilisateur, connecte une base Firebase gratuite. C'est offert
par Google (plan Spark = gratuit), sans carte bancaire.

--------------------------------------------------------------
ETAPE 1 — Creer le projet Firebase
--------------------------------------------------------------
1. Va sur https://console.firebase.google.com et connecte-toi avec un
   compte Google.
2. Clique "Ajouter un projet" -> donne un nom (ex: plan-de-bataille)
   -> tu peux desactiver Google Analytics -> "Creer le projet".

--------------------------------------------------------------
ETAPE 2 — Activer l'authentification
--------------------------------------------------------------
1. Menu de gauche -> "Build" -> "Authentication" -> "Get started".
2. Onglet "Sign-in method" :
   - Active "E-mail/Mot de passe" (Email/Password) -> Enregistrer.
   - Active "Google" -> choisis un e-mail d'assistance -> Enregistrer.

--------------------------------------------------------------
ETAPE 3 — Creer la base de donnees (Firestore)
--------------------------------------------------------------
1. Menu de gauche -> "Build" -> "Firestore Database" -> "Creer une base".
2. Choisis un emplacement (ex: europe-west) -> commence en mode
   "production".
3. Onglet "Rules" (Regles) : colle EXACTEMENT ceci, puis "Publier" :

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}

(Ces regles font que chaque utilisateur ne peut lire/ecrire QUE ses
propres donnees. Important pour la securite.)

--------------------------------------------------------------
ETAPE 4 — Recuperer la configuration
--------------------------------------------------------------
1. En haut a gauche, roue crantee -> "Parametres du projet".
2. Descends jusqu'a "Vos applications" -> clique l'icone Web </>.
3. Donne un surnom (ex: site) -> "Enregistrer l'application".
4. Firebase affiche un objet "firebaseConfig" avec apiKey, authDomain,
   projectId, etc. Garde cette fenetre ouverte.

--------------------------------------------------------------
ETAPE 5 — Coller la configuration dans le site
--------------------------------------------------------------
1. Ouvre le fichier "firebase-config.js" (dans ce dossier) avec un
   editeur de texte.
2. Remplace chaque valeur "VOTRE_..." par la valeur correspondante de
   ton firebaseConfig. Exemple :
     apiKey: "AIzaSyD...ton_vrai_code..."
     authDomain: "plan-de-bataille.firebaseapp.com"
     projectId: "plan-de-bataille"
     storageBucket: "plan-de-bataille.appspot.com"
     messagingSenderId: "123456789"
     appId: "1:123456789:web:abcd..."
3. Enregistre le fichier.
(Remarque : la "apiKey" Firebase n'est PAS un secret ; elle est faite
pour etre publique. La securite vient des regles de l'etape 3.)

--------------------------------------------------------------
ETAPE 6 — Deployer et autoriser ton domaine
--------------------------------------------------------------
1. Reglisse tout le dossier du site sur https://app.netlify.com/drop.
2. Note l'adresse de ton site (ex: mon-site.netlify.app).
3. Dans Firebase -> Authentication -> onglet "Settings" ->
   "Authorized domains" -> "Add domain" -> ajoute ton adresse Netlify
   (ex: mon-site.netlify.app). Sinon la connexion Google refusera le
   domaine.

--------------------------------------------------------------
C'EST FINI
--------------------------------------------------------------
Ouvre ton site, clique "Compte" en haut a droite : tu peux t'inscrire,
te connecter, ou continuer avec Google. Les conversations du Tuteur IA
se sauvegardent alors sur le compte et te suivent sur tous tes appareils.

Tant que firebase-config.js n'est pas rempli, le bouton "Compte"
affiche simplement un message : le reste du site fonctionne normalement.

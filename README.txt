Plan de Bataille — Plateforme de revision 1ere Bac Sciences Maths (Saad)
=======================================================================

MISE EN LIGNE (Netlify) : https://app.netlify.com/drop  -> glisser ce dossier (ou le ZIP).
Page principale : index.html

INSTALLER L'APPLICATION (PWA) :
  Une fois le site en ligne (https), ouvre-le sur ton telephone :
   - Android/Chrome : menu ... -> "Ajouter a l'ecran d'accueil".
   - iPhone/Safari : Partager -> "Sur l'ecran d'accueil".
  Une icone apparait comme une vraie app, et les cours marchent HORS-LIGNE.

PAGES :
  index.html     -> Accueil : plan de l'annee, echecs, calendrier, rituels
  revision.html  -> Cours complets (48 chapitres) : lecon + exercices + corrections,
                    ecoute vocale, et boutons "Compris / A revoir" (progression)
  qcm.html       -> QCM interactifs auto-corriges (144 questions, toutes matieres)
  flashcards.html-> Cartes memoire a repetition espacee (144 cartes)
  progres.html   -> Progression par matiere + minuteur Pomodoro + carnet d'erreurs
  examens.html   -> 4 examens blancs du regional + corriges (PDF)
  youssef.html   -> Coran : Sourate Yusuf, texte + explication en arabe, ecoute verset par verset
  data.js        -> banque de QCM et flashcards
  sw.js, manifest.json, icons/ -> application installable hors-ligne

NOUVEAU (onglet Maths) :
  - Grapheur interactif GeoGebra (Graphique / Geometrie / Calculatrice) dans Revision > Maths.
  - Une video de cours (prof) dans chaque lecon de maths (bouton Cours en video).
  - Necessite une connexion internet (GeoGebra + YouTube).

NOUVEAU :
  - Gamification : XP, niveaux et badges (gagnes en faisant QCM/cartes/Pomodoro).
  - Tableau de bord (page Progres) : carte de maitrise, courbe de scores, temps d'etude.
  - QCM : mode examen chronometre + defi du jour (10 questions, communes chaque jour).
  - Page Outils : calculateur de moyenne (coefficients reels) + simulateur de note du Bac,
    formulaire de formules cherchable, et recherche globale sur tout le site.

NOTES :
  - Tout ton travail (progression, cartes, Pomodoro, carnet, cases) est sauvegarde
    dans TON navigateur (prive a ton appareil).
  - Le texte de la Sourate Yusuf et l'audio (Coran) se chargent depuis des sources
    en ligne fiables : connexion internet requise pour ces deux-la.
